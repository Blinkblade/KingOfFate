## 1. 操作规则（一句话）

```text
只用 A / S / Z / X   → 不耗气的普通招式
带 C                 → 消耗 300~400 气的中型技能
带 D                 → 消耗 600~800 气的大型技能
C + D 同按           → 终极技（2000 气）
```

**方向表达意图**（总纲 §3.4，不增加按键）：

```text
← + 气键 = 拉开距离      → + 气键 = 突进      ↓ + 气键 = 压制/破防
```

## 4. 情境覆盖检查（总纲 §3.6）

| 维度 | 覆盖情况 | 结论 |

| 高度 下段 | 230 / 240 / 410 / 440 / 610 / 630 / 640 | ✅ |

### 空缺①：没有明确的"上段"招式

`1100 升斬` 本该是上段对空，但实测判定框来自 kuri 的 action 1050，算出来落在**中段**。
→ **下一步**：把 1100 的判定框上移（判定框 y 抬到 -130 以上），让它真正成为上段反制招。

### 空缺②：被反制后的"脱身"手段尚未验证

总纲 §3.8 要求"任何一次被反制后，玩家总有一个已知且便宜的脱身选项"。
当前候选：`←C 后撤投剑`（400 气）—— 但它**耗气**，不算"便宜"。
→ **下一步**：需要一个不耗气的脱身手段（如空中受身 / 后跳），见阶段 2。

## 5. 标签算法（改了 .air 就重跑）

```
距离：外缘 = max(Clsn1 的 x1/x2) × 0.48   →  <55 近 / <80 中 / ≥80 远
高度：判定框 y 的中位                     →  < -95 上 / < -55 中 / 否则 下
速度：起手 tick                           →  ≤8 快 / ≤12 中 / >12 慢
```

（`×0.48` 是因为引擎把 Clsn 乘以 `size.xscale`，见总纲 §4.1）

## 6. 三段时序原则（总纲 §3.2 / §3.8）

- **收招必须存在**：每招都有 4~15 tick 的收招 → 这就是**可被确反的窗口**
- **超必杀例外**：Super(40) / UBW(198) **保持长** —— 它们是稀有的"大反馈"，值得等待
- **起手短**：普通技起手 1~10 tick；技能起手 9~12 tick（慢起手 = 可预读）
