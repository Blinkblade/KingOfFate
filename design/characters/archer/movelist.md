## 0. 操作规则

```text
只用 A / S / Z / X   →  不耗气的普通招式
带 C                 →  消耗 300~400 气的中型技能
带 D                 →  消耗 600~800 气的大型技能
C + D 同按           →  终极技（耗满气 2000）
```

方向键表达**意图**：`←` 拉开 · `→` 突进 · `↓` 压制/破防 · `↑`（空中）追打

## 2. 每招的用途

| 对手在做什么 | 我用什么 | 靠什么赢 |
|---|---|---|
| 中距离站着防 | `A` 轻斩抢 / `→D` 突进斩压迫 / `D` 幻想崩坏 | 起手 5 tick，最快 |
| 中远距离 | `S` 重斩（外缘 84，全角色最长） | 距离 |
| 蹲着防 | `↓C` 斜下射箭 | 打蹲姿 |
| 站著防 | `↓D` 跳劈下压 | 破防（overhead） |
| 跳在空中 | `→C` 升斬（唯一上段，y −160~−92） | 上段对空 |
| 贴脸 | 投技 | 破防 |
| 被逼近 | `←C` 后撤投剑 | 拉开 + 反制 |
| 远距离空档 | `C` 射箭 | 飞行道具牵制 |
| 满气 | `C+D` 无限剑制 | 全屏 |

## 3. 本轮做完的事

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 判定窗口 | 13 招只有 **1 tick**（打起来像擦过去） | 全部 **3 tick / 3 帧** |
| 四个气键技能判定框 | 统一占位值（外缘 85） | 按各自素材实测：62 / 58 / 60 / 104 |
| 投技 | **没有伤害行** → 造成 0 伤害 | 60 伤害 |
| 扫堂腿 | 8 tick（"重"招却最轻） | 15 tick，有收招 |
| 空轻脚 / 空重脚 | 12 / 15 tick，空中会飘 | 20 / 15 tick |
| 受击框 | 13 个动作在出招期间**无敌** | 全部覆盖整段 |
| 投射物判定框 | **11 个投射物动画完全没有 Clsn1** → 气键技能零伤害 | 全部按精灵尺寸补上 |

## 4. 已知待调项

| # | 项 | 说明 |
| --- | --- | --- |
| 1 | **扫堂腿 / 空重脚起手 = 0** | 判定窗口从第 0 帧就开始，等于"瞬发"。要改成有起手，把窗口往后移 2~3 帧 |
| 2 | 四个气键技能的**垂直判定带**是统一算法给的 | 外缘按素材实测了，高度带（y −105~−35）没逐帧精调 |
| 3 | **伤害数值仍是继承来的** | 轻斩 25 / 重斩 60 / 升斬 75 … 需按新时序重新配平 |
| 4 | 音效是"按频次猜"的映射 | 需试听指定哪个是打击感、哪个是格挡声 |
| 5 | 上段只有 `→C` 一招 | 覆盖检查显示上段偏薄，是否加第二招待定 |
