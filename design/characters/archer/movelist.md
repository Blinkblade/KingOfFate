## 0. 操作规则

```text
只用 A / S / Z / X   →  不耗气的普通招式
带 C                 →  消耗 300~400 气的中型技能
带 D                 →  消耗 600~800 气的大型技能
C + D 同按           →  终极技（耗满气 2000）
```

方向键表达**意图**：`←` 拉开 · `→` 突进 · `↓` 压制/破防 · `↑`（空中）追打

### ★ 闪身解决的是什么问题

箭矢飞得高、跳不过去，而原来没有突进手段 → **射箭方 camping 无解**（只能一直防或挨打）。
闪身就是那个解：前 2 帧**无受击框**，可以穿过箭矢接近；后 14 tick 恢复受击框，**甩空会被惩罚**。

三条设计约束：
- **不耗气** —— 它是对付压制的唯一手段，收费就失去意义
- **前段无敌 + 后段可惩罚** —— 整段无敌会变成无敌把戏
- ⚠️ 无敌的实现方式：前 3 帧**不声明任何 `Clsn2`**（解析出 nil = 无敌）。
  **不能写 `Clsn2: 0`** —— 那是"空数组"而非 nil，引擎（`char.go` 用 `Clsn2 == nil` 判断）不认为无敌
- ⚠️ 位移的实现方式：`velSet` 必须写在**状态级**（每 tick 生效）。
  写在 `if time = 0` 里**只生效一帧**，人物不会移动（照抄 `common1.cns.zss` 的前冲写法）
- **只能从自由状态发动** —— 不能取消攻击，否则可以无限闪

## 2. 每招的用途

| 对手在做什么 | 我用什么 | 靠什么赢 |
|---|---|---|
| 中距离站着防 | `A` 轻斩抢 / `→D` 突进斩压迫 / `D` 幻想崩坏 | 起手 5 tick，最快 |
| 中远距离 | `S` 重斩（外缘 84，全角色最长） | 距离 |
| 蹲着防 | `↓C` 斜下射箭 | 打蹲姿 |
| 站著防 | `↓D` 跳劈下压 | 破防（overhead） |
| 跳在空中 | `→C` 升斬（唯一上段，y −160~−92） | 上段对空 |
| 贴脸 | 投技 | 破防 |
| 被逼近 | `←C` 后撤投剑 | 拉开 + 反制 |
| 远距离空档 | `C` 射箭 | 飞行道具牵制 |
| 满气 | `C+D` 无限剑制 | 全屏 |
