## 0. 三条设计前提

```text
只用 A / S / Z / X   →  不耗气的普通招式
带 C                 →  消耗 300~400 气的中型技能
带 D                 →  消耗 600~800 气的大型技能
C + D 同按           →  终极技（耗满气 2000）
```

**方向键额外表达"意图"**（不加任何按键）：

| 输入 | 意图 |
| --- | --- |
| `←` + 气键 | 拉开距离 |
| `→` + 气键 | 突进接近 |
| `↓` + 气键 | 压制 / 破防 |
| `↑`（空中） | 对空 / 追打 |

**每招都必须有一条"可被确反的收招"**（总纲 §3.2）——这是深度的来源，不是可选项。

## 1. 普通招式（12 个，不耗气）

## 7. 我在现有数据里发现的问题（与上表独立）

| 招 | 问题 |
