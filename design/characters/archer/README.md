## 1. 定位

**中远距离弓手 / 近战二刀流混合型 Zoner。**

与 Fighter B 的区别只在表达层：气弹→箭矢、升龙→二刀升斬、弹幕→幻想崩坏。
数值骨架（tick、判定框、伤害、气）在换美术完成前**先沿用 Fighter B 实测值**，
换装后按素材实际几何复核（见 §6 验收）。

核心循环（继承 Zoner 已验证逻辑）：

1. 在 95 px 外用**箭矢**压制（投射物骨架 = Fighter B 1000）。
2. 被接近用**干将·莫邪长手斩**（长手骨架 = 210，双刀延伸天然合理化长手）。
3. 跳入交给**蹲上挑斬 / 升斬**（对空骨架 = 410 / 1100）。
4. 贴身用**投技**推开（800/810）重获发箭距离。
5. 资源：500 气 = 双连矢（EX）；1000 气 = 幻想崩坏（Super）；
   2000 气 = 无限剑制（第二 Super，见 §3 范围说明）。

## 3. 无限剑制的 P6 范围（负责人已指定，范围在此写明）

负责人指定终极招为无限剑制。P6 交付**玩法完整、演出简化**的版本：

- **P6 版本**：咏唱起手（可复用 Super pose）+ 多段剑雨投射物
  （8~12 把剑从上方/侧面射向对手区域，单发伤害低、总量大，全程无敌或对投射物无敌待定）+
  需要的新美术仅**剑的投射物精灵**（1~2 个角度）。
- **P7 强化范围**（不在 P6）：固有结界背景替换、superPause 定格演出、
  咏唱语音与台词、镜头运动。
- 理由：完整 UBW 演出依赖背景替换与大量特效精灵，属于表现层强化（P7）；
  P6 先保证"终极招存在、可发动、可命中、扣费正确、有证据"。

## 4. 美术方向与基准

- **形象**：白发（白头）、肤色偏黑、红衣（Archer 战斗服）、黑白双刀（干将·莫邪）、
  弓（干蒼？Archer 的弓是黑色复合感）。
- **显示比例**：沿用引擎默认（与 KFM/测试角色同台可战）；脚底基准=原点 y 轴落地面，
  朝向=素材默认面向右（引擎自动翻转处理 P1 侧）。
- **调色板**：源素材即色；不做 12 色调色板系统（非商用同人，无需换色功能）。
- **镜像策略**：双刀/衣服左右不对称细节在验收时逐帧核对（见 §6）。
- **素材来源**：P6 第一版用 kuri 的 MUGEN Archer（2005，SFF v1，已下载并登记）。
  **2026-09-30 决定换精度更高的源**：负责人要求"现阶段素材越精细越好，方便后期 AI 重绘"。
  经查证，原计划路线"C. 用《Fate/Unlimited Codes》街机精灵"**不可行**——FUC 是 3D 建模
  游戏，没有 2D 精灵表（The Spriters Resource 上该游戏资产数为 0）。
  改为使用 **`EMIYA (Custom Sprited High Res)` by aka65535 / Sho**（2017 手绘高清版），
  它同样是 MUGEN 角色包 → 现有 SFF 流水线**无需新增切割工具**即可使用。
  落地位置与下载说明见 [`assets/imports/archer_hires/README.md`](../../assets/imports/archer_hires/README.md)。
  来源、作者、许可登记进 `assets/LICENSE_MANIFEST.csv`（usage=noncommercial_fanwork）。

## 6b. 简化指令（P6 施工期临时版）与正式指令对照

**为什么要简化**：负责人用键盘手搓很难稳定复现 236 / 623 / 236236 这类指令，
无法判断"这招到底做好了没有"。因此在施工期先给一套**方向 + 单个按键**的指令，
验证通过后正式交付时改回 KOF 搓招。

**为什么选 `c` / `z` 两个键**：本角色是 KOF 四键（x/a/y/b = A/B/C/D），
`c` 与 `z` 在四键体系里完全空闲，所以「↓+c / ←+c / →+c / ↓+z / ←+z」
与 12 个普通技、投技（前/后 + y/b）**一个都不冲突**。
刻意不用 ↑：按 ↑ 会先起跳，随后按键会被引擎当成空中攻击，语义含糊。

| 招式 | 简化指令（现在） | 正式指令（交付时） | 状态 |
| --- | --- | --- | --- |
| 射贯（射箭） | `↓ + c` | `236 + A` | 1000 |
| 双连矢 EX | `← + c` | `236 + C` | 1010 |
| 升斬（对空） | `→ + c` | `623 + A` | 1100 |
| 幻想崩坏 Super | `↓ + z` | `236236 + A` | 3000 |
| 无限剑制 | `← + z` | `214214 + A` | 3100（待实现，暂接 3000） |

**备份与恢复办法**（三处，缺一不可）：

1. **正式招式表**：`moves.csv`（本目录）——从未被简化版覆盖，是数值与指令的真值。
2. **正式指令定义**：`game/chars/archer/archer.cmd` 里的
   `QCF2_x / QCF_x / QCF_y / DP_x` 四条**保持原样未删**（只在其后新增了
   `SIMPLE_*` 五条）。恢复 = 删除 `[Command]` 里 `SIMPLE_*` 五段 +
   `command.zss` 里的「④b 简化指令」整段。
3. **素材来源角色的原始指令表**：`assets/imports/archer/emiya/emiya.cmd`
   （kuri 原作者的 72 条指令，未改动）——若将来要对照原作搓招，以此为准。

> 改回正式指令后**必须**重跑：玩家输入 → 状态路由（Gate 6 的取消链与气账证据
> 依赖真实搓招窗口），并复核 `.cmd` 的顺序优先级（QCF2 必须在 QCF 之前）。
