## 1. 定位

**All-rounder（均衡型）玩法测试角色。**

P3 的目标不是做一个正式角色，而是回答一个问题：
`_template` 能不能稳定生产出"独立、可玩、有完整攻击体系"的 Fighter？

所以设计原则是 **Gameplay > Art**，并且刻意选择：

| 选择 | 理由 |
| --- | --- |
| 招式数量刚好覆盖四层（普通 / 必杀 / EX / Super） | 多一层就多一份验证成本，对"验证生产路径"没有增量价值 |
| 每招一个明确用途（近 / 远 / 对空 / 突进 / 扫倒） | 便于在运行时逐招观测并判定"这招到底有没有生效" |
| 不做复杂机制（无反射、无蓄力、无姿态切换） | 复杂机制会掩盖模板本身的问题 |
| 复用 KFM 占位素材的精灵与判定框几何 | 精灵就是 KFM 的，KFM 的框天然对得上；P3 不做美术 |
| 只做 1 个 Super、1 个 EX | 验证机制成立即可，不做数量堆叠 |

## 3. 核心玩法（这个角色想让你怎么打）

1. **轻技起手 → 段位推进**：`A/B`（lv1）确认命中或至少进入判定帧后，
   取消进 `C/D`（lv2）补伤害，再取消进必杀（lv3）收尾。
   整套取消链最长 4 段。
2. **中距离是主战场**：`Special 1` 突进 22 px 能从中距离直接压进去；
   `Special 2` 20 tick 以上的起手不适合主动出手，专门用来惩罚跳跃。
3. **下段是压力工具**：蹲轻拳/蹲轻脚都是下段（只能下防），
   蹲重脚命中直接扫倒并进入倒地压制节奏。
4. **资源决定爆发**：500 气换一次 EX 击倒；1000 气换一次 200 伤害的 Super。
   气槽上限 2000，所以"一整条气"= 1 Super + 2 EX 的选择题。

## 4. 与模板（`_template`）的分工

| 内容 | 归属 |
| --- | --- |
| 文件结构、命令层/路由层/状态层的分工、变量台账约定 | **模板** |
| 站立四键、投技（800/810/820/821）、气槽与取消的写法约定 | **模板** |
| 蹲攻、跳攻、第二个必杀、EX 改造、Super、等级化取消链、独立 AI | **Fighter A** |
| 占位 SFF/SND（KFM 素材） | 模板带来了同一份；Fighter A 继承，**发布前必须替换** |

开发中发现的**模板**问题（手册缺步骤、脚本输出误导）已在
`game/chars/_template/README.md` 与 `scripts/sync_game_content.ps1` 里就地修正，
而不是只在 Fighter A 里绕过。
