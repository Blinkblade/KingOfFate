## 1. 定位

**Zoner（远程控制型）玩法测试角色。**

P4 的目标不是做一个正式角色，而是回答一个工程问题：

> 同一个 `_template` 与同一套角色体系，能不能承载一个**风格完全不同**的角色，
> 以及两个角色之间的真实战斗？

所以设计原则是 **Gameplay > Art**，并且刻意选择与 Fighter A 的每一步都相反：

| 选择 | 理由 |
| --- | --- |
| 主力手段是投射物，不是突进 | Rushdown 已经有 Fighter A 了；投射物是"远程控制"最直接的表达，也顺带验证引擎原生 `projectile{}` |
| 长手用**判定框**做，不用位移做 | 合同 §10.2 明确要求：不能靠"瞬移"伪装成长手。真长手必须付出起手/收招代价 |
| 对空分成 Normal 与 Special 两档 | 验证"同一功能可以分两个层级实现"，也让 AI 有条件做选择 |
| Super 做成"弹幕"而不是"更大的一拳" | Zoner 的 Super 意义在于改变局面，不在数值堆叠 |
| 复用 KFM 占位素材的精灵与几何 | 精灵就是 KFM 的；P4 不做美术 |

## 3. 核心玩法（这个角色想让你怎么打）

1. **先在 95 px 以外站住**。这个距离是 AI 的投射物阈值，也是本角色的主场。
   气弹速度 6 px/tick，对手必须做选择：防 / 跳 / 前冲 / 硬吃。
2. **被接近就换工具**：55–140 px 用长手 `210`（到 x=105）挡住接近路线；
   被贴到 45 px 以内就用最快的 `200` 应急，或者投技把对手推开。
3. **跳进来的对手交给对空**：近而快用 `410`（y=-112），远而高用 `1100`（y=-152）。
   两者判定都集中在胸以上，因此**对地面低姿目标打不到** —— 这是设计意图，不是 bug。
4. **资源用来压制而非爆发**：500 气 = 双发；1000 气 = 三连弹幕。
   气槽上限 2000，所以"一整条气"= 1 Super + 2 EX，或 4 次 EX 的选择题。

## 5. 明确不做（留给后续阶段）

- 平衡（伤害模型、胜率、Tier）：P10
- 表现层（superPause 定格、镜头、闪光、暗转、胜利台词）：P7
- 原创美术与音效、投射物专用精灵：**P5**（当前投射物借用的是 KFM 的 `1000,4`，
  一个**完整人形**，所以画面上像"一个人飞出去"）
- 投射物判定框按正式素材重画：**P5**（当前尺寸是为兼容占位素材实测调出来的）
- Utility AI / Self-play / 强化学习：P9 / P10
- 角色继承系统、技能 DSL、代码生成器：**不做**（合同 §29 禁止过度设计）

## 6. 已知设计限制

1. 投射物判定框（±40 × ±60）是**基于占位素材实测调出来的**，不是从美术尺寸推导的；
   P5 换素材后必须重画。
2. 对空命中（对手在空中被 1100/410 打中）的验证依赖合成注入，
   本机注入能力在 P4 期间受限（见 Phase Report §3）。
3. 蹲攻 / 跳攻的部分起动帧数从 `.air` 帧表推导，未逐项做伤害实测
   （Fighter A 的 12 个普通技在 P3 已全测，可作为对照）。
