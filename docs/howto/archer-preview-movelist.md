# Archer 预览：出招表与试玩方式（P6）

> 本文是 **P6 正式角色 `archer` 建成之前**的试玩指引。
> 现在能在菜单里选到的是**素材来源角色** kuri 的 Archer/EMIYA（带原作者自己的 CNS 逻辑），
> 用途是让负责人**看到并打到** P6 要用的正式美术。
> `game/chars/archer`（Zoner 骨架，自己的 ZSS 逻辑）建好后，本文与 `select.def` 里的
> 两条预览条目都应删除，改用 [`design/characters/archer/moves.csv`](../../design/characters/archer/moves.csv)。

---

## 1. 怎么启动

**方式 A：菜单里选（推荐）**

```powershell
pwsh -File scripts\run_game.ps1
```

选人界面里会多出两个预览条目：`Emiya V2`（我们转码的 SFF v2）与 `Emiya`（原版 SFF v1，
用于对照）。两者画面上应当一致——这是 P6 素材链路的**无损性证明**。
对准 P2 槽位按 轻拳键（`Z`）或 START（`Enter`）可切到 2P 手动对战。

**方式 B：命令行直接进对战**

```powershell
pwsh -File scripts\run_game.ps1 -ExtraArgs '-p1','emiya_v2','-p2','test_fighter_b','-s','stage0','--windowed'
```

## 2. 键位（P1 默认，`save/config.ini` 已确认是引擎默认值）

| 功能 | 按键 |
| --- | --- |
| 方向 | `↑` `↓` `←` `→` |
| 轻拳 按钮 `x` | **`A`** |
| 强拳 按钮 `y` | **`S`** |
| 重拳 按钮 `z` | **`D`** |
| 轻脚 按钮 `a` | **`Z`** |
| 强脚 按钮 `b` | **`X`** |
| 重脚 按钮 `c` | **`C`** |
| START | `Enter` |

记法约定：`F/B/U/D` = 前/后/上/下（以角色面向为准，1P 面向右时 F = `→`）。
数字串用键盘/摇杆记法：`236` = `↓ ↘ →`，`41236` = `← ↙ ↓ ↘ →`，`623` = `→ ↓ ↘`。
