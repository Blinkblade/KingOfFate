## 3. 没做 / 做到不到位的（诚实清单）

### 3.1 三件仍是 Fighter B 占位（**我复核时才发现，之前没意识到**）

| 文件 | 现状 | 后果 |
| --- | --- | --- |
| `archer.snd` | **与 `test_fighter_b.snd` MD5 完全相同** | Archer 打人/被打全是 KFM 音效。素材包里有一套 21MB 的 Archer 音效（含语音）**完全没用上** |
| `archer.const` | 与 `test_fighter_b.const` **完全相同** | 体型、速度、跳跃、伤害全是 Fighter B 的数值，**没有按 Archer 调过** |
| `AI.zss` | 与 `test_fighter_b.AI.zss` **完全相同** | CPU 用 Fighter B 的招式表与节奏（状态号相同所以能跑），没按 Archer 的射程/节奏适配 |

### 3.2 判定框从未按 Archer 美术重画

- 所有 `Clsn1`（攻击判定）与 `Clsn2`（受击判定）仍是 **P4 按 KFM 占位素材实测的数值**。
- 高清素材是 162×249（kuri 是 54×120，**面积约 6 倍**），轴心、身高、推挤盒、
  投射物发射偏移**全部需要重算**。
- `const [Size]` 现在是 `xscale=1 / yscale=1`，直接换成高清精灵会让角色变成三倍大。

### 3.3 映射里仍有多处"就近替代"，未逐个目检

- 走路（源帧数不足 → 循环填充）、`5←8`、`6←9`、`100←105`、`181←196`、
  `800←810`、`1100←1050`、`5300←5120` 等替代表
- 高清源另有 `11/41/42/43/181/9001` **六个组缺失**，需要新的替代表

### 3.4 玩法与表现层

- **Cancel 链（Gate 6）证据未按最终美术重取**
- `movelist.dat` 还是简化指令标注
- 没有选人头像（高清源只有 `9000` 两张，缺 `9001`）
- 换色（高清源自带 6 套调色板：Alter / CCC / FGO / Nameless / fsd2p / uc2p）未利用

### 3.5 工具链缺口

- **没有 SND 读取器**（P5 明确写了"无 SND 工具"）→ 想用 Archer 音效必须先补这件

### 3.6 收尾

- `docs/P6-summary.md` 未写、PR 未提、未合并 `main`
