## 2. 已完成

### 2.1 方向（总纲，2026-10-02 定版）

- **人人能放**：没有任何搓招。A/S/Z/X = 不耗气普通招式，带 C/D = 耗气技能。
- **量大管饱**：20 个招式（12 普通 + 8 气键技能）。
- **反制为纲**：深度来自「用自己的招式拆解对手的选择」，不是连段。
- **操作分层只有一条规则**：只用 A/S/Z/X → 不耗气；带 C/D → 耗气。C、D 键之前完全空闲，所以这个分层**不需要新增按键、不改引擎键位、不重做状态机**。

### 2.3 角色

- 美术：高清素材（1803 精灵 / 423 动作，站立 162×249）
- **21 个攻击招式全部做完**：12 普通 + 投技 + 4 中型（带 C）+ 3 大型（带 D）+ 1 终极；另有 3 种闪身
- **闪身**（方向 + `A`+`Z` 同时按，键盘为 `→`/`←`/`↓` + `a`+`z`，KOF97 的 A+B）：前 12 tick 无敌 + 后 8 tick 可被惩罚，不耗气
- 每招都有**可被确反的收招**（9~20 tick）
- 伤害按「风险 × 回报」配平：轻 24 / 中 30 / 重 46~84 / C 档 50~66 / D 档 78~84 / 终极 160
- 退役代码（旧 EX 1010）已删除

### 2.3d 玩法规则修正（2026-10-31）

复核时发现四处**出招表/注释写着的规则，代码并没有兑现**。共同点：都不报错、都能玩，只是承诺是空的。

| # | 问题 | 之前 | 现在 |
| --- | --- | --- | --- |
| 1 | **射箭不扣气** | 出招表写 300 气、路由要求 300 气，但状态里没有扣气行 → **300 气可无限射** | 1000 加 `powerAdd{value: -300}` |
| 2 | **升斬不扣气** | 同上，承诺 400 | 1100 加 `powerAdd{value: -400}` |
| 3 | **幻想崩坏多扣气** | 路由只要 800 气，状态里扣 1000 → 扣穿到 0，"800 可放"变成"必须攒 1000" | 改成 `-800`，与出招表/movelist.dat 一致 |
| 4 | **闪身收招仍在滑** | 状态级 `velSet` 每 tick 重写速度，`if time = 12` 置的 0 下一 tick 被覆盖 → 后 8 tick 可惩罚窗口**不存在** | 位移按 `time < 12` / `time >= 12` 分段 |
| 5 | **跳劈不是 overhead** | `guardflag: MA` = 上下都能防，但出招表、用途表、AI 注释都写"overhead 破防" | `guardflag: H` = 只能站防 |

配套：**AI 直接 `changeState`，绕过 `command.zss` 的气量门槛** → 给 AI 的射箭规则补上 `power >= 300`，否则 AI 零气照样白嫖（扣气被引擎夹在 0）。

同时修正了出招表里的两处过期说法：闪身是 **12 tick 无敌 + 8 tick 可惩罚**（原文写"前 2 帧 / 后 14 tick"），无敌段按动作切成 4~6 个元素但总长必须正好 12 tick。

## 6. 文档中已记录的教训（防重演）

- 换任何资源（精灵/音效/调色板）都要**重映射引用 + 有校验规则兜底
- Bash heredoc 会吞反斜杠，导致正则**静默失配** → 用 `[0-9]` 或字符串处理
- 精灵可以用**形状分析**（填充率/行宽分布）判断是人物 / 剑 / 特效帧，不必依赖看
- 输入测试失败时，先怀疑测试装置，再怀疑角色（已踩过两次：字母键注入不通、按键时机太早）
