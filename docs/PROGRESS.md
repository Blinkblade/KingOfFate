## 2. 已完成

### 2.1 方向（总纲，2026-10-02 定版）

- **人人能放**：没有任何搓招。A/S/Z/X = 不耗气普通招式，带 C/D = 耗气技能。
- **量大管饱**：20 个招式（12 普通 + 8 气键技能）。
- **反制为纲**：深度来自「用自己的招式拆解对手的选择」，不是连段。
- **操作分层只有一条规则**：只用 A/S/Z/X → 不耗气；带 C/D → 耗气。C、D 键之前完全空闲，所以这个分层**不需要新增按键、不改引擎键位、不重做状态机**。

### 2.2 工具链

| 工具 | 能力 |
| --- | --- |
| `sffpack` | SFF v1→v2 转码 + 重编号；`--force-palette` |

- `AIR_NO_HURTBOX` 在「带攻击框却无受击框」时升级为 **WARNING**
- `ZSS_MISSING_SOUND`：状态脚本引用的音效键不在 `.snd` 里 → **ERROR**

## 6. 文档中已记录的教训（防重演）

- 换任何资源（精灵/音效/调色板）都要**重映射引用 + 有校验规则兜底
- Bash heredoc 会吞反斜杠，导致正则**静默失配** → 用 `[0-9]` 或字符串处理
- 精灵可以用**形状分析**（填充率/行宽分布）判断是人物 / 剑 / 特效帧，不必依赖看
- 输入测试失败时，先怀疑测试装置，再怀疑角色（已踩过两次：字母键注入不通、按键时机太早）
