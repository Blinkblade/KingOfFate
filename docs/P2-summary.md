## 3. 五条必须知道的事实（都带实测出处）

1. **`command.zss` 的顺序就是优先级**，窄条件必须写在宽条件之前（P1 E5）。
2. **`.air` 的帧数 = 手感**；`Clsn1`（攻击框）与 `Clsn2`（受击框）互相独立、
   且都与伤害解耦（P1 E4）。本轮实测：轻拳与重拳的框型差异肉眼可见。
3. **`hitDef.damage` 精确等于掉血量**（P1 E2）。本轮逐条复测：
   A 25 / C 70 / 投技 90（走 `targetLifeAdd`）/ 必杀近 95、远 85 / EX 130。
4. **`const power` 是气槽上限，不是起始值**；对局起点为 0，**气量跨回合保留**
   （V18/V19 实测：第 1 回合充满 → 第 2 回合仍是 1000）。
   收入 = 命中给气（≈0.7×伤害）+ `poweradd`；支出 = 路由层 `power >= 500`
   + 状态内 `powerAdd{value: -500}`。
5. **引擎调试热键可以被合成注入触发**（F3 = 充满气、F1 = 击杀对手、F5 = 回合计时归零）。
   它走引擎输入路径，与"角色命令层只有 TAB/RETURN 可达"是两条不同通道 ——
   攒气、快速造出回合结束等联调动作因此可以自动化。

## 4. 本阶段明确**不做**的

- 蹲攻（400–440）、跳攻（600–640）、超杀（3000+）：状态号与命令已预留，
  路由里 `command != "holddown"` 已为蹲攻留好位置。
- 多姿势胜利表演（181–189）、胜利台词：属 P7 表现层。
- 任何"框架化"尝试（继承系统、生成器、DSL、第二套气槽/取消系统）：合同 §29 禁止。

## 5. 每个克隆角色的硬要求

1. **替换 `_template.sff` / `_template.snd`**：现在是 P1 研究用的 KFM 占位素材
   （Elecbyte，**CC-BY-NC**，`usage = prototype_only`，已登记 `assets/LICENSE_MANIFEST.csv`）。
   发布前必须换成原创美术与音频。
2. 全目录 `_template` → `<你的角色名>`（文件名 + `.def` 的 `name` + 文件引用；
   清单见模板手册 §2）。
3. 改名后跑 `scripts/test.ps1`；**任何改动路由顺序或 AI 顺序之后必须重新跑运行时观测**。
